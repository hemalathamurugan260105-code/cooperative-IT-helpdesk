# Cooperative IT Helpdesk

A web-based IT Helpdesk Management System designed to simplify communication between users and IT administrators. The system allows users to create and track support tickets, while administrators can manage, update, and resolve tickets efficiently.

## Features

### User
- User registration and login
- Secure authentication using JWT
- Create IT support tickets
- View submitted tickets
- Track ticket status
- View ticket details

### Admin
- Secure admin authentication
- View all user support tickets
- Manage and update tickets
- Update ticket priority and status
- Add resolution notes
- View ticket details
